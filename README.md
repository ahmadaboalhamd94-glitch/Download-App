# Download App — GitHub Pages

نسخة Static تعمل على GitHub Pages فقط، بدون Python أو Flask.

## النشر
1. ارفع `index.html` إلى مستودع GitHub.
2. Settings → Pages.
3. Build and deployment → Deploy from a branch.
4. اختر `main` و`/ (root)` ثم Save.
5. بعد النشر استخدم رابط `https://USERNAME.github.io/REPOSITORY/`.

## حدود GitHub Pages
GitHub Pages لا يشغل Python/Flask/yt-dlp. النسخة تدعم روابط ملفات الفيديو المباشرة مثل MP4/WebM التي يسمح مصدرها بالوصول من المتصفح. لا يمكنها تحويل روابط YouTube/TikTok إلى ملفات فيديو باستخدام GitHub Pages وحده.
